# Dev Playbook（PoC / 個人開発用）

このリポジトリは、PoC・個人開発・小規模Webアプリ開発における
**思考手順・判断基準・AI活用方法をテンプレート化**するための playbook である。

## 目的
- PoCを高速に回す
- AIを役割分担して安全に使う
- 技術テンプレを資産として再利用する

## 対象
- 自主アプリ開発
- 小規模Webアプリ
- 将来の拡張を見据えたPoC

## 技術テンプレとの関係
- テンプレA：静的コンテンツ（Astro / Cloudflare Pages）
- テンプレB：PWA（Vite / React / TypeScript）
- テンプレC：Webアプリ本命（Pages + Workers）

本playbookは**手順・考え方の正本**とし、技術テンプレとは分離して管理する。
